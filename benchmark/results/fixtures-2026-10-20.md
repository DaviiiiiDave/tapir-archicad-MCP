# Benchmark fixtures, 2026-10-20

Seeded with `python benchmark/cli.py seed german|scale|international` on Archicad 29 (German), Tapir 1.7.2, and
checked with `python benchmark/cli.py seed --verify`: `german: verify ok`, `scale: verify ok`,
`international: verify ok`. Each verify opens the fixture fresh and derives every set again from the project.

TestProject as a .pla loads no Archicad library, only the parts placed in it. It has no door, so the Door tool
default points at a door and a marker that are not loaded, and Tapir `CreateDoors` fails for every door with
`-2130313115 Failed to prepare door defaults` (APIERR_BADID), also when `libraryPartName` names a loaded door.
With the packs the German template loads (`Archicad Bibliothekspakete/*.libpack`) the tool default works unchanged.

T4 buckets: an out-of-band write of the property to each wall that cannot be edited, on a throwaway copy.

| Cause | Walls | Official API | Tapir |
|---|---|---|---|
| locked layer | 10 | `6001 TeamWork permission denied` | `-2130312909 Failed to set property value for element` |
| hotlink | 10 | `6001 TeamWork permission denied` | `-2130312909 Failed to set property value for element` |

Both causes return the same error from both APIs. Grouping failures by error code alone cannot tell them apart.
